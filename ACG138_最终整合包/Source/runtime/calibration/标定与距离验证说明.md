# 双目相机标定与距离验证

物理镜头顺序为eye0左眼、eye1右眼。显示镜头切换只影响画面选择，标定参数仍按物理左右眼使用。

## 已有标定结果

原始采集日期为2026-10-31。单眼分辨率960×1080，棋盘9×6内角点，格长25mm。eye0单目RMS为1.5212817像素，使用68张图；eye1为1.5432191像素，使用70张图。

固定单目内参，用共同通过筛选的67对图像拟合双目参数。RMS为1.5275109像素，基线34.86393mm。校正后角点纵向差的中位数为0.27185像素，95分位为0.85424像素。旋转矩阵正交，左右视差符号正确，三角化点均在相机前方。

24对留出图中有14对检出角点，12对的校正纵向差95分位不大于2像素，另2对为2.017和12.013像素，其余10对角点提取失败。部分留出图参与过单目标定，因此该检查集并非完全独立。

拟合数据距离约0.94～1.82m，留出图可检测范围约0.83～1.71m。棋盘格长与PnP比较属于内部一致性检查。打印比例、安装外参、移动场景精度及0.20m近距测量仍需尺量验证。

## 文件位置

运行目录的calibration/包含mono-eye0.conf、mono-eye1.conf、objects-calibration.bin和stereo-extrinsics.json。
单目配置保存各眼内参及畸变；objects-calibration.bin为OSD1运行表，输入单眼960×1080，校正输出240×270；stereo-extrinsics.json描述左光学坐标到右光学坐标的变换X_right=R*X_left+T。
该双目外参不包含相机到车体的安装关系。

Source/calibration/measured/保存单目标定和双目拟合的JSON报告。原始NPZ、采集图及角点缓存未包含在本包，重新拟合需另行提供输入。运行参数位于上述conf及bin文件中。

## 重新采集与标定

在电脑的整合包目录下打开PowerShell。以下命令的Data、Results指向自行保存的采集及结果目录。

```powershell
cd Source
$Data = 'calibration/本次采集目录'
$Results = 'calibration/本次结果目录'
python calibration/calibrate.py mono --images "$Data/eye0/*.png" --eye 0 --cols 9 --rows 6 --square-m 0.025 --max-rms 2.0 --output "$Results/eye0.npz"
python calibration/calibrate.py mono --images "$Data/eye1/*.png" --eye 1 --cols 9 --rows 6 --square-m 0.025 --max-rms 2.0 --output "$Results/eye1.npz"
```

两眼文件名需成对。完成单目标定后执行双目拟合和运行表导出。

```powershell
python calibration/calibrate.py stereo --left "$Data/eye0/*.png" --right "$Data/eye1/*.png" --left-calib "$Results/eye0.npz" --right-calib "$Results/eye1.npz" --cols 9 --rows 6 --square-m 0.025 --max-rms 2.0 --output "$Results/stereo.npz"
python objects/export_calibration.py --input "$Results/stereo.npz" --output "$Results/objects-calibration.bin" --left-eye 0 --scale 0.25 --extrinsics-output "$Results/stereo-extrinsics.json" --physical-side-verified
```

参数导出后先做尺量检查，再备份并替换RK运行目录中的对应文件。

## 近距测量范围

240×270校正输出下焦距约713.38像素，基线约0.034864m，视差近似为713.38×0.034864/Z。
64档视差理论下限约0.395m，128档约0.196m，192档约0.130m。遮挡、纹理及共同视野会进一步缩小有效范围。min_depth_m配置值本身不能证明该距离可测。
双目输出是相机光学轴方向Z。换算到车头表面距离还需车体安装偏置。

## 尺量验证

先在车辆停止状态下，用有纹理的纸盒测试0.5、1.0和1.5m，再检查0.3及0.2m。记录真实尺量值、双目距离、有效点数和失败原因。
透明、反光、纹理不足或遮挡会使双目无效，此时按现有逻辑使用方向、雷达或目标记忆，并保留无效原因。
转动镜头对焦、改变分辨率或裁剪、移动摄像头后需重新标定。标定分辨率使用原始单眼图像尺寸。
