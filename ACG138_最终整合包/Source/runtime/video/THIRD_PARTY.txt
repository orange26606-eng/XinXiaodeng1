The runtime loads the exact packaged library by an absolute application-private
path. It does not overwrite a system MPP library or alter the existing DSI/NPU
dynamic library search path. Headers permit rebuilding this integration; building
MPP itself requires the corresponding SDK/upstream sources, not bundled here.

Host integration tests use tests/mock_mpp.c and a generated FFmpeg baseline AVC
fixture. The mock is never installed, selected by begin, or published as a board
runtime .so. Passing those tests is not evidence of a physical encoder test.
